# Vue 3 设备管理前端 Implementation Plan

**Goal:** 使用服务端管理员登录，查看全部设备，为每台设备保存游戏配置。

**Architecture:** Vue 3 + TypeScript + Vite 单页前端；同源 Yii Admin API 使用 session 与 CSRF。开发演示 API 仅在 demo 模式启用，数据来源在界面明确标记。生产构建连接真实 Yii API。

**Visual thesis:** 深墨绿色侧栏、温暖灰白工作区、绿色主操作，紧凑设备表格与清晰的大数字统计。

**Content plan:** 登录 → 设备总览/筛选/列表 → 游戏选择弹窗；游戏库提供目录及配置数量。

**Interaction thesis:** 登录与工作区轻量入场；设备行 hover 强化操作；弹窗过渡与保存反馈，尊重减少动态效果设置。

## Validation

前端运行 `npm test` 和 `npm run build`；后端运行专用单元/功能测试及 `php -l`。浏览器验证演示模式，不向真实设备写入测试配置。没有心跳数据的真实设备显示“状态未知”，不使用更新时间推断在线。

2026-10-11 验证结果：前端 20 项测试、类型检查与 `/console/` 生产构建通过；后端 46 项测试、185 个断言及 PHP 语法检查通过。浏览器已验证登录错误、正确登录、游戏保存与刷新持久化、保存失败保留原配置、搜索筛选、分页、退出重登、弹窗键盘焦点及 390px 移动端布局。

真实 A1 游戏目录只读请求当前返回空列表；演示环境明确使用 12 台示例设备和 6 款示例游戏。真实 MySQL 联调和 Docker 镜像构建/运行尚未验证，未执行部署。
