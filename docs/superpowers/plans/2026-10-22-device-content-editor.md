# 设备欢迎词与图片配置

**目标：** 在现有网页设备配置弹窗中保留游戏选择，增加与小程序一致的设备名称、口号（欢迎词）、图片地址和缩略图地址列表编辑。

**方案：** 复用设备 `setup.title`、`setup.slogans`、`setup.pictures`、`setup.thumbs`。增加 现有管理 JWT 保护的 `PUT /admin-api/devices/{id}/configuration`，接受白名单字段的局部修改；游戏变更继续校验目录，内容单独修改不依赖游戏目录。现有 `/game` 接口保持兼容。设备列表返回三个列表，未建配置的设备读取不产生写入。列表保存时去掉首尾空白和空项，显式空数组用于清空。设备名称使用 `setup.title`，去首尾空白且最多 255 个 Unicode 字符，允许清空；列表名称优先显示非空且非默认“未知”的标题，再回退至设备标签/UUID，不修改标签或 UUID。金额、镜头等其他设置保持原值。

界面沿用当前绿色风格和弹窗，提供设备名称输入框和三个可增删列表，图片及缩略图支持 HTTP(S) 地址预览。草稿与设备数据隔离，取消不保存；游戏不变或为空也可以单独保存内容。保存中禁用编辑与关闭，失败保留草稿；空目录或目录加载失败不阻止内容编辑。演示环境同步支持保存和重启后的读取。

**取舍：** 扩展原游戏接口会混淆内容编辑语义；拆成多个保存按钮会产生部分保存。采用独立局部更新接口，在同一事务中保存本次改动。
